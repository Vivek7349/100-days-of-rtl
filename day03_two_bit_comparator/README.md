# 080226-day03-two-bit-comparator

## Overview
This project implements a **2-bit comparator circuit** using Verilog HDL.  
The comparator compares two 2-bit unsigned inputs and produces three outputs indicating whether the first input is **greater than**, **equal to**, or **less than** the second input.

Only **one output is asserted HIGH at a time**, ensuring correct comparison behavior.

---

## Functional Description

### Inputs
- **A** : 1-bit input operand A  
- **B** : 1-bit input operand B  

### Outputs
- **Greater** : HIGH when A > B  
- **Equal**   : HIGH when A = B  
- **Lesser**  : HIGH when A < B  

---

## Working Principle

The comparison is performed using **combinational logic** with priority given to the most significant bit (MSB).

- The MSBs of A and B are compared first.
- If the MSBs are equal, the LSBs are compared.
- The Equal output is generated by checking equality of both bits.
- Greater and Lesser outputs are generated using AND, NOT, and comparison logic.

This approach ensures correct magnitude comparison while maintaining a simple and synthesizable design.

---

## RTL Design Details
- Fully combinational design  
- No clock or sequential elements  
- MSB-first comparison logic  
- Synthesizable RTL  
- Implemented using basic logic gates  

### RTL File
- rtl/comparator_2bit.v

## Verification

The design is verified using a testbench that applies all possible input combinations for a 2-bit comparator.

The simulation confirms that:
- Greater is asserted when A > B
- Equal is asserted when A = B
- Lesser is asserted when A < B
- No two outputs are asserted simultaneously

- tb/tb_comparator_2bit.v
