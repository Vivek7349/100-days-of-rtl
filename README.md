# 100 Days of RTL Design

This repository documents my **100-day RTL design challenge**, where I design,
implement, and verify **one digital circuit per day** using Verilog/SystemVerilog.

## Objectives
- Build strong RTL fundamentals
- Practice testbench-based verification
- Develop industry-style project organization
- Create a public, reviewable design portfolio

## Tools
- Verilog / SystemVerilog
- Icarus Verilog / ModelSim / Questa (as applicable)
- GTKWave
- Git & GitHub
- Linux & Windows workflow

## Repository Structure
Each day contains:
- `rtl/` – synthesizable RTL code
- `tb/` – testbench
- `sim/` – simulation outputs
- `README.md` – design description

## Progress
| Day | Design |
|----|-------|
| Day 01 | AND Gate |
| Day 02 | NAND Gate |
| Day 03 | Half Adder |
| ... | ... |

## Rules
- One complete design per day
- RTL + testbench mandatory
- Code must be clean and synthesizable
- Commit daily
